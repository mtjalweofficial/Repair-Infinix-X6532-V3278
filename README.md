###Flashing Instructions for the Technician:

1. Remove the battery (turn off the device completely).

2. Open the SP Flash Tool.

3. Select the flashing files (load MT6768_Android_scatter.txt and select boot.img only).

4. Select the "Download Only" mode (Warning: Do not format or erase user data).

5. Click the Download button in the program.

6. Connect the phone: Plug in the charging or data cable, then immediately press and hold both the Volume Up and Volume Down buttons (Vol Up & Down) simultaneously.

7. Wait until the flashing completes successfully (a green checkmark will appear).

8. If an error occurs or flashing does not start, disconnect the device and try again.
